# Exemplo de Directive: Verificação de Setup

Este SOP define como verificar se a instância do agente foi configurada corretamente.

## Objetivos
- Validar a existência dos diretórios base.
- Testar a execução de um script determinístico.

## Entradas
- Nenhuma.

## Execução
- Rodar o script `execution/verify_setup.py`.

## Saídas
- Relatório de status no terminal.
